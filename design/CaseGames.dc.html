The game factory

Every game starts from the same template and goes through the same gates. AI does the heavy lifting; the checks keep it honest.

  1. 01Game briefWhat it teaches, the mechanic, the content.
  2. 02Claude DesignEvery screen and state, art and key frames.
  3. 03/new-game skillCopies the starter, builds phase by phase to the export.
  4. 04verify:gameTypes, tests, build, no external requests in the bundle.
  5. 05Site handoffSynced into Astro, landing page, GA4 events, live.

Engineering that players never see

Right-to-left, done rightHebrew is never reversed in code. Fixed an RTL placement bug in Phaser on high-DPI screens, and fonts load before any text is drawn so vowel marks render correctly.
Audio that can't break the gameOne audio context per game, unlocked by a tap. A missing sound is silent, never a crash. Generated speech is cached and its cost logged.
Phone and desktopLarge touch buttons, forgiving jump timing, full keyboard play. Layout maths is tested from 568×320 to 1920×1080.
Built to includeReduced motion respected, contrast checked by tests, feedback never by colour alone, every prompt works without sound.
Not done yet

Honest gaps

  • No offline mode yet — the games need a connection.
  • Game content is drawn on canvas, so screen readers can't read it.
  • Three games use generated speech; a native-speaker review is still in progress.
  • Too early for usage numbers — the series is one month old.
